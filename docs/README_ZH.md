# 硬件资料

`documents.yaml` 是每个板卡的资料登记表，记录官方来源、版本、获取日期、适用范围和再分发状态。
登记表只提供可追溯引用，不替代厂商当前发布的原始文档。

PDF 和 3D 文件默认标记为 `link-only`。合法获取的本地副本放在
`layers/bsp/docs-local/<board>/`，该目录不会纳入 Git。若某个下载文件被用于设计决策，应先在
`documents.yaml` 中记录其 SHA-256 和版本，再引用该文件。

代码依赖的硬件事实（引脚、总线、地址、复位顺序、strapping 和电源轨）保留在板级后端及其
README 中；不要在源码注释里复制整份数据手册，而应引用登记表条目和具体的板级文件。
